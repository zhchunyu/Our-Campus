# 铭贤学堂旧址 · 自由游览

一个**纯前端、可离线**的 360° 全景漫游页，用于展示山西铭贤学校旧址（今山西农业大学校内）。
不依赖 OurCampus，不依赖后端，整套拷贝走就能用。

**另外已打包成独立 Android APK：[`铭贤学堂-全景游览-1.0.apk`](铭贤学堂-全景游览-1.0.apk)（49.45 MB）** —— 见[第九章](#九android-apk)。

- 17 个全景场景，可拖动环视、滚轮/双指缩放
- 场景条 + 上一处／下一处自由切换，也可键盘 ← →
- 8 段讲解配音，支持**一个场景多段**（如崇圣楼 + 尚德堂共用一张全景）
- 自动巡游：按游览动线自动切换并连续讲解
- 全屏、加载进度、桌面优先的界面

## 一、怎么打开

> ⚠️ **不能直接双击 `index.html`。**
> 页面用了 ES Module + importmap，浏览器出于安全限制，`file://` 协议下不会加载模块。
> 必须通过一个本地 HTTP 服务打开。

### 方式 A：双击启动脚本（推荐）

双击 **`启动游览.cmd`**，脚本会：

1. 自动找一个没被占用的端口（8080 起）；
2. 打开浏览器访问 `http://127.0.0.1:<端口>/index.html`；
3. 关掉那个黑窗口就停止服务。

脚本会优先用 `py`，其次 `python`，再其次 `node`。三者都没有时会提示安装方式。

> **注意：`启动游览.cmd` 是 GBK 编码保存的。**
> Windows 批处理按本地代码页解析文件，原先用 UTF-8 保存会导致中文变乱码、语法被破坏、
> 脚本中途退出（表现为双击闪退、地址打不开）。已修正为 GBK。
> 如果今后用编辑器改这个文件，请**保持 GBK/ANSI 编码**，不要存成 UTF-8。

### 方式 B：手动起服务

```powershell
# 有 Python
python -m http.server 8080 --bind 127.0.0.1

# 或者有 Node.js
node tools/serve.mjs 8080
```

然后浏览器打开 `http://127.0.0.1:8080/index.html`。

### 方式 C：部署到静态空间

把整个文件夹上传到任意静态托管（校园服务器、对象存储、GitHub Pages……），
直接访问该目录下的 `index.html` 即可。**线上要用 HTTPS**，否则陀螺仪等能力会受限。

## 四、改内容

### 改场景名称、说明、配音

编辑 `app/data.js`：

```js
'2171': {
  name: '崇圣楼',
  note: '崇圣楼建筑群所在院落。',
  audio: 'assets/audio/chongshenglou.mp3',   // 改成 null 就没有配音
},
```

- `name` 显示在顶栏、场景条、说明卡
- `note` 是左下角的场景说明
- `audio` 指向 `assets/audio/` 下的文件

### 调整游览顺序

改 `app/data.js` 里的 `ORDER` 数组，顺序即「上一处/下一处」和自动巡游的走向。

### 给没有配音的场景加配音

### 给场景加配音 / 调整归属

在页面里就能配，不用改代码：

1. 点右上角「讲解库」；
2. 点某段配音的「试听」，听一下内容；
3. 用右边的下拉框选它该配给哪个场景 —— **立即生效**（场景条会出现标记，多段显示数字）；
4. 配完点「导出绑定配置」，得到一段 JSON，可回填到 `app/data.js` 长期固化。

支持**一个场景多段配音**：把两段音频都指派到同一场景即可，播放器会显示 `配音 1/2`、
`配音 2/2`，一段播完自动接下一段。

> 指派结果先存在浏览器本机（`localStorage`）。换设备或清缓存会丢失，
> 所以正式交付前请用「导出绑定配置」把结果写回 `data.js`。
> 点「恢复默认」可清空本机改动。

### 一个场景多段配音

- 播放器会显示 `配音 1/2 · 崇圣楼`，点 **⏭** 切到下一段，`↻` 重播当前段；
- 一段播完会**自动接下一段**，全部播完才停；
- 场景条上，单段显示一个小圆点，多段显示数字（如崇圣楼显示 `2`）；
- 自动巡游时，同一场景的多段会连续讲完再切下一处。

### 换全景图

1. 把新的等距柱状全景（2:1）放进 `C:\Users\<你>\Downloads\OurCampus-铭贤学堂素材\panoramas\`，
   命名规则 `<场景号>_<名称>.jpg`；
2. 运行 `tools/prepare_assets.py`（需要 Pillow），会自动生成三档产物；
3. 若新增了场景号，记得同步 `app/data.js` 的 `SCENES` 和 `ORDER`。

## 六、常见问题

**一进页面就弹出「讲解库」，关不掉，看不到游览图**
- 已修复。原因是 CSS 里给 `.sheet` 设了 `display: grid`，覆盖了 HTML `hidden` 属性的
  `display: none`，导致弹层始终显示并盖住首屏。现在全局加了 `[hidden] { display: none !important; }`。
- 如果你的浏览器还显示旧样子，按 **Ctrl+F5** 强制刷新清掉缓存的旧 CSS。

**双击 `启动游览.cmd` 闪退 / 黑窗口一闪而过**
- 多半是没有 Python 或 Node.js；脚本结尾有 `pause`，正常应停在提示上。
- 若窗口一闪而过且没提示，检查是不是把 `启动游览.cmd` 单独复制出来了 ——
  它需要和 `index.html`、`app\`、`vendor\`、`assets\` 在同一目录。

**浏览器显示"无法访问此网站" / `ERR_CONNECTION_REFUSED`**
- 服务没起来。看黑窗口里是否打印了 `地址：http://127.0.0.1:8080/index.html`；
  没有打印说明脚本提前退出了。
- 关掉黑窗口服务就停了，**窗口要一直开着**。

**页面打开一片空白**
- 不能直接双击 `index.html`（`file://` 下 ES Module 会被拦），必须走上面的本地服务。
- 按 F12 看 Console，正常不应有任何红色报错。

**改了 cmd 之后中文变乱码**
- 这个文件必须是 **GBK/ANSI** 编码，不能存成 UTF-8。

**端口被占用**
- 脚本会自动从 8080 往上找，最多到 8099；都被占用时会提示。

## 七、已知限制

- **必须用本地服务打开**，不能双击 html（ES Module 限制）。
- 桌面单场景全景 1.2–2.8 MB，首次进入某场景会有短暂加载；已按需加载，不做全量预载。
- 暂未做场景间的方向性热点（画面里的箭头），当前用场景条 + 左右切换。
- 暂未做字幕；有文稿后可加。
- 陀螺仪在 iOS 上需 HTTPS 且需用户点击授权。
- 微信内置浏览器不保证全屏与陀螺仪，建议用系统浏览器打开。

### 技术实现

一个极简 WebView 壳，没有引入 Capacitor/Cordova：

| 关键点 | 做法 |
| --- | --- |
| 本地资源加载 | `WebViewAssetLoader` 把 `assets/www/` 映射到 `https://appassets.androidplatform.net/assets/www/`，避免 `file://` 下 ES Module 被 CORS 拦掉 |
| importmap 兼容 | `psv.module.js` 内部 13 处裸模块名 `from "three"` 已改写成 `from "./three.min.js"`，因此不依赖 importmap（老 WebView 也能跑） |
| localStorage | 开启 `setDomStorageEnabled(true)`，讲解库的绑定能保存 |
| 自动播放配音 | `setMediaPlaybackRequiresUserGesture(false)` |
| 全屏 | 沉浸式全屏 + `FLAG_KEEP_SCREEN_ON`（演示时屏幕不灭） |
| 权限 | 无（不需要网络、存储、相机、定位） |
