# 地点开放与关闭影子试跑样本

样本为虚构校园场景，共 200 对「事件 × 用户状态」，包含 88 个不同事件。38 个常规场景用于对比同一事件面对不同订阅与收件条件时的决定。50 个困难反例分别使用不同的事件和原文，在 `hardCase` 字段中标记。所有时间字段以判断时刻为 0，单位为分钟。

| 预期动作 | 全部样本 | 困难反例 |
| --- | ---: | ---: |
| 立即提醒 `now` | 63 | 0 |
| 延后至可用时段 `digest` | 19 | 0 |
| 只在站内呈现 `inbox` | 52 | 17 |
| 跳过 `skip` | 66 | 33 |

困难反例包括 7 条旧闻、8 条否定表述、8 条疑问或待确认事项、8 条未核原文的转发或仍缺有效时限的线索、8 条夹带对分析程序的指令、6 条撤回记录和 5 条过期记录。用户状态覆盖明确订阅、主动接收收藏地点更新、弱相关、无匹配、无可见权限、未开启兴趣提醒、发布者本人、已读、重复、系统提醒关闭、仅站内、安静时段、摘要设置及当日频率上限。边界用例覆盖最晚有用时刻恰好到达和候选提醒时刻恰好等于最晚有用时刻。

每对样本的 `expected.action` 与 `expected.reason` 均按试点规则逐例指定。`user.canView` 给出场景中的来源可见资格，`subscribed`、`favoriteOptIn` 和 `weakMatch` 描述相关程度。`event` 的来源、状态和有效时限是已给定的结构化输入。影子试跑仅验证这批已给定输入下的动作选择。文本抽取、来源核验、真实用户相关性和真机到达需分别取证。样本及预期标签由同一代理编制，正式准入仍需独立人工验收集。
