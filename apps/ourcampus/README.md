# OurCampus · 校园地图与社区

以手机校园地图为入口，连接地点、导航、社区、账号、餐厅窗口和课表。前端使用 React + Vite，安卓使用 Capacitor，账号与社区聊天使用 Supabase；AI 通过服务端网关调用 AUV。

本目录位于共享仓库的 `apps/ourcampus`。当前源码进入 **1.20 开发版（versionCode 21）**，新增11月10日AI上下文与相关聊天提醒；该开发版尚未打包。已用原证书构建并发布的 **1.19（versionCode 20）** 是 [GitHub 体验版](https://github.com/zhchunyu/Our-Campus/releases/tag/v1.19)，匿名回下载核验通过；Supabase 应用内更新仍由项目管理员发布，当前线上版本为 1.18。1.19 包含社区图片、精简个人页，以及本轮主动推送接入。安装与验证见 [1.19 主动推送发布交接](docs/releases/OurCampus-1.19-主动推送发布交接.md)，图片与个人页背景见 [开发交接](docs/releases/OurCampus-1.19-图片与个人页交接.md)。

当前采用 **场景创新赛道** 要求，依据附件 1《场景创新赛道赛题及竞赛规则》和附件 2 技术报告参考大纲。材料要求、评分与七部分报告结构见 [场景创新赛道规则](../../archive/competition-rules/README.md)。旧 AI 软件创新赛道要求不再作为当前提交依据。

## 快速运行

环境：Node.js **22.12 或以上**、npm。已有仓库的同学先拉取最新代码；首次使用：

```powershell
git clone https://github.com/zhchunyu/Our-Campus.git
cd Our-Campus/apps/ourcampus
Copy-Item .env.example .env.local
npm ci
npm run dev -- --host 0.0.0.0
```

启动前向项目负责人索取开发配置，填入 `.env.local`：腾讯地图 Key、Supabase 根地址及 Publishable key。Supabase 根地址不带 `/rest/v1/`。需要本机 AI 网关时，另外填写 `AUV_BASE_URL` 和 `AUV_API_KEY`。字段见 [.env.example](.env.example)，真实配置不在仓库中。

打开终端显示的地址。手机浏览器预览需要与电脑在同一网络，使用电脑局域网 IP；`127.0.0.1` 只指当前设备。公开部署与 APK 使用的服务地址应能从手机访问。

### 电脑上预览（与手机同尺寸）

```powershell
npm run dev:desktop
```

会启动 Vite（默认 `http://127.0.0.1:5180`）并自动打开浏览器，页面中间是 430 × 880 的手机画面，画面里的 iframe 就是手机版界面，交互与真机一致，改代码自动热更新。Windows 也可直接双击 `启动电脑预览.cmd`。端口被占用时用 `$env:OURCAMPUS_PREVIEW_PORT=5181` 换一个；只想用普通浏览器窗口打开可访问根地址或加 `?preview=mobile`。

```powershell
npm run build         # 网页生产构建，输出 dist/
npm run ai:serve      # 可选：独立 Node AI 网关，默认本机 8787
npm run android:apk   # 构建网页、同步 Capacitor 并生成 debug APK
npm run android:share # 通过本机网络分享已生成的 APK
```

## 当前功能与数据范围

| 功能 | 当前实现 |
| --- | --- |
| 校园地图与导航 | 腾讯 2D 地图、默认 17 级、缩放范围 14–20 级、地点搜索和详情、按需 GPS 定位、校园道路规划及手机腾讯地图导航入口。已合入队友 2026-10-11 的名称与坐标校准，73 个地点中 61 个使用采集坐标，12 个仍为估算；名称和坐标按稳定地点 ID 关联。地图使用原生边界锁定，校园标注矩形约占可移动面积 20%，南侧额外避让底部菜单。 |
| 账号 | Supabase 邮箱注册、密码登录、数字验证码确认、密码重置、修改昵称、会话恢复；实际邮件投递依赖服务器 SMTP 和模板配置。 |
| 大厅聊天 | Supabase 消息存储和 Realtime 订阅、按地区筛选、历史分页、撤回本人消息、重连同步及轮询补偿；需服务器 RLS、消息表和实时广播配置正确。 |
| 你画我猜 | 社区里的纯前端小游戏：Realtime Broadcast 同步笔画、Presence 显示在线玩家，不写数据库、不新增表和函数；按地区开房，「谁点谁画」，分数只在当前会话内，暂无排行榜。 |
| 餐厅评价 | 谷园一层六个真实窗口及菜单参考；管理员维护窗口，按窗口评分、推荐 / 吐槽筛选。云端评价需队友部署 11、12 号 SQL；部署前可保存本机评价，不混入真实统计。 |
| 热点、失物、校园消息 | 主动上报、异步 AI 分析、候选关联、管理员审核、全员 / 订阅通知、持久未读消息。队友需部署 09、10 号 SQL 与工作函数；历史本机信息不自动上传。 |
| 地点反馈、报修、收藏 | 地点反馈可选上云；报修完整工单仍为本机原型，收藏、常用路线和附近设施继续本机保存。 |
| 安卓系统推送 | 已接个推 SDK、权限同意、CID 绑定和通知点击；1.19 已配置公开 AppID，用户主动开启后登记设备。聊天通知默认关闭，按五个地区逐项订阅；前台新提醒排队，点击详情可回到对应地区。后台实际送达及厂商离线通道仍待真机验收。 |
| 课表 | 支持现有教务 `.xls` 导入、本机按账号保存；1.18 加入每日安排、日期条、正在上课 / 下一课和一次教学周校准，保留手动浏览的周次与日期。尚未直接接入教务账号或完成课表云端同步。 |
| 应用内检查更新 | Android 启动时检查，设置中可手动检查；管理员上传并发布版本记录后，旧版可显示新版说明并打开受控 APK 下载地址，由用户下载安装。普通账号不能发布版本，不会静默安装或替换运行中的代码。 |
| AUV 校园助手 | 用户主动发送内容，经鉴权网关调用模型；可携带主动选择的地点与课表上下文。模型服务可用性由服务部署决定，未自动读取全部大厅消息或后台 GPS。 |
| 启动与手机适配 | 1.13 使用用户提供的新版 4 秒竖屏品牌视频，静音、保持比例播放，同时加载应用；播放失败回退到静态图标。桌面图标为深蓝底白色 C 与蓝色圆点，提供圆形、自适应及主题单色图层。 |

真实账号角色由服务器读取，前端不能自行提升为管理员。室内导航尚缺可靠楼层图，不作为已完成能力。历史方案中的演示角色、旧地图和旧接口描述，以当前代码及上述范围为准。

1.14 调整：采用微信式灰白界面、系统字体与小图标；大厅改为社区；服务页增加 AI 入口，校园服务扩充到 16 项并显示官方办理入口；网页边缘滑动、浏览器返回和 Android 系统返回按层级处理。安装包的资源、版本和签名已核对，实体手机侧滑仍待安装后验收。

1.15 调整：采用 A 清爽校园界面，修正服务页通知铃铛随内容滚动；加入重要/相关通知设置、失物候选匹配与个人 AI 上下文的客户端更新。通知新能力需同学部署 14 号增量 SQL 和工作函数后生效，六项个人管家功能目前仍为开发交接方案。APK 资源、版本和旧版同证书签名已核对，29 项针对性检查通过，实体手机仍待安装验收。

## 安卓安装与构建

1.18 安装包入口：[GitHub Release](https://github.com/zhchunyu/Our-Campus/releases/tag/v1.18)。本次使用原签名生成非 debuggable 的 release APK，证书与保留的 1.17 一致；实体手机覆盖安装仍待验收，Supabase 应用内更新记录已发布。核验与交接见 [1.18 发布记录](docs/releases/OurCampus-1.18-发布交接.md)。历史 [1.16 安装包](docs/apk/OurCampus-1.16-校园装扮与全屏地图.apk) 和 [验证记录](docs/reviews/2026-10-16-apk-1.16.md) 继续保留。

1.18 更新：合入队友的每日课表修复，校准后按上海当前日期展示当天安排与下一课；未校准时保留手动选择，不将猜测日期当作今天。沿用头像、个人主页与应用内检查更新功能。课表仍按账号保存在本机。

自行构建需要 **JDK 21、Android SDK API 36**（当前 Build Tools 35.0.0）及 Gradle 依赖。优先复用已有环境。设置 `JAVA_HOME`，并在不提交的 `android/local.properties` 中填写本机 `sdk.dir`。运行 `npm run android:apk` 后，产物位于 `android/app/build/outputs/apk/debug/app-debug.apk`。

保留当前 applicationId，升级时递增版本号。不要把服务器密钥改成 `VITE_` 字段；所有 `VITE_` 配置会进入网页和 APK。首页定位仅由用户点击触发，无后台持续定位。

用户提供的图标原稿位于 `public/assets/brand/ourcampus-teammate-icon-1024.png`，开屏视频位于同目录的 `ourcampus-startup.mp4`。需要重新生成图标尺寸时运行 `scripts/generate-launcher-icons.py`，使用已有 Python/Pillow；可通过 `--source` 指定其他正方形 PNG。转换时保留原图内容，为 Android 自适应图标留出中央安全区。
