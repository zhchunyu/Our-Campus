## 更新反馈群二维码

1. 将维护者提供的原图按更新日期保存，保持二维码原始像素，不重新绘制或有损压缩。
2. 同步更新根 README 的图片路径、替代文字、更新日期和原图有效期。
3. 旧图移至本目录的 `archive`，不再用作当前扫码入口。
4. 始终保留 [Issues](https://github.com/zhchunyu/Our-Campus/issues) 作为二维码失效或群满时的长期反馈渠道。

当前页面与设计截图统一保存在[设计目录](../design/README.md)，并注明版本及测试数据范围。
