# 铭贤学堂旧址「自由游览」纯前端页面方案

> 版本：v1 方案（2026-11-18）
> 目标：不接入 OurCampus，做一个**独立、纯静态、双击即开**的 360° 全景自由游览页
> 输入素材：已下载 17 张全景原图（4480×2240）+ 8 段配音 MP3

---

## 1. 目标与范围

### 1.1 要做什么

一个纯前端页面，打开就是铭贤学堂旧址的全景，可以：

- 自由拖动/缩放视角，手机可开陀螺仪；
- 在 17 个场景之间自由切换（场景条 + 上/下一个 + 可选方向热点）；
- 每个场景播放对应配音讲解（可暂停/重播/静音）；
- 点场景里的兴趣点看史料卡片（文字/图片）；
- 一键「自动巡游」：按顺序自动切换场景并连续讲解；
- 全屏、加载进度、移动端适配，断网也能用。

### 1.2 不做什么（本期）

- 不做后端、不做登录、不做后台管理；
- 不接 OurCampus、不使用 Supabase；
- 不做题库/打卡/证书（可作为第二阶段）；
- 不做真正的三维模型漫游（现有资源是全景，不是 3D 模型）。

### 1.3 两种交付形态

| 形态 | 说明 | 适用 |
| --- | --- | --- |
| A. 本地文件夹 + 启动脚本 | 双击 `启动游览.cmd` 打开本地服务，浏览器访问 | 答辩/展示现场、无网络 |
| B. 静态托管 | 上传到任意静态空间（校园服务器、GitHub Pages、对象存储） | 扫码分享、长期访问 |

两种形态同一套代码，B 只是把文件夹传上去。

## 2. 现有素材与缺口

| 素材 | 现状 | 处理 |
| --- | --- | --- |
| 全景图 | 17 张，4480×2240，单张 7–14 MB | 压到 4096×2048 / 2048×1024 两档，WebP/JPEG |
| 配音 | 8 段 MP3，共约 3.2 MB | 保留 MP3（兼容性最好），统一响度 |
| 场景名称 | 17 个（外门、外院、校长院、崇圣楼…） | 直接使用 |
| 场景拓扑 | **缺**：谁和谁相邻、从哪个方向走过去 | 先做「场景条切换 + 上/下一个」；方向热点后补 |
| 热点坐标 | **缺**：yaw/pitch | 二阶段从后台标记页导出，或在页面里手工打点 |
| 讲解文稿 | **缺** | 需你提供或后续转录；没有字幕就先只放音频 |
| 兴趣点内容 | **缺** | 需人工撰写史料卡（校史馆口径） |
| 平面示意图 | 无 | 可选：手绘一张简化平面图做导航 |

> 结论：**没有坐标也能做「自由游览」**——用场景条 + 前进/后退 + 陀螺仪，体验已经完整；方向性热点是加分项，不阻塞。

## 3. 技术选型

### 3.1 三个方案对比

| 方案 | 体积 | 能力 | 上手成本 | 结论 |
| --- | --- | --- | --- | --- |
| **Photo Sphere Viewer 5**（three.js 内核，MIT） | 约 700 KB（含 three） | 手感最好、标记/陀螺仪/自动旋转插件齐全、支持多分辨率 | 中 | **推荐** |
| Pannellum（单文件，MIT） | 约 120 KB | 热点、场景、自动旋转、指南针，够用 | 低 | 备选/极简版 |
| 自己写 three.js 球体 | 约 600 KB | 完全可控 | 高 | 不必要 |

**推荐 PSV 5**：拖动惯性和移动端手感明显更好，Marker 插件能直接放「去往某处」的箭头和史料点，后续加坐标成本最低。

### 3.2 依赖与构建

- **不引入构建工具**：原生 HTML + CSS + ES Module，库文件放本地 `vendor/`，用 `<script type="importmap">` 指向本地文件。
- 好处：改一行刷新即可、不需要 Node、可整体拷贝、离线可用。
- 若后续要压缩合并，再加一个可选的 Vite 配置，不影响现在的结构。

### 3.3 目录结构（建议）

```
mingxian-tour/
├─ index.html
├─ 启动游览.cmd            # Windows 双击启动本地服务
├─ app/
│  ├─ main.js              # 入口：加载场景、路由、UI
│  ├─ viewer.js            # PSV 初始化、场景切换、销毁
│  ├─ ui.js                # 场景条、播放器、卡片、自动巡游
│  ├─ data.js              # 场景数据（内嵌，避免 file:// 的 fetch 限制）
│  └─ style.css
├─ vendor/                 # PSV + three 本地文件
├─ assets/
│  ├─ panoramas/           # 4096 宽，WebP
│  ├─ panoramas-mobile/    # 2048 宽，WebP
│  ├─ previews/            # 512 宽缩略图 + 64 宽模糊占位
│  ├─ audio/               # 8 段 MP3
│  └─ covers/              # 分享卡片、封面
└─ README.md               # 使用与替换素材说明
```

## 4. 交互设计：怎么「自由游览」

### 4.1 首屏

```
┌──────────────────────────────────────┐
│  铭贤学堂旧址 · 自由游览              │
│                                      │
│        [ 全景画面 / 封面 ]            │
│                                      │
│        [ 开始游览 ]  [ 自动巡游 ]      │
└──────────────────────────────────────┘
```

- 「开始游览」才会初始化 WebGL 并播放音频（绕开浏览器自动播放限制）。
- 首屏背景用外门的预览图，不加载大图。

### 4.2 游览界面

- 顶部：标题 + 当前场景名 + 全屏按钮。
- 底部：**场景条**（17 个缩略图横向滑动，当前高亮）。
- 右下角：`‹ 上一处` / `下一处 ›` 按固定顺序走。
- 左下角：讲解按钮（播放/暂停/重播）、音量、字幕开关。
- 画面中：方向热点（二阶段）与兴趣点（史料卡）。
- 快捷键（桌面）：← → 切换场景，空格播放/暂停，F 全屏，G 陀螺仪。

### 4.3 自动巡游

- 预设一条路线（建议：外门 → 外院 → 校长院 → 崇圣楼 → 内院 → 石板院 → 侧门 → 观赏楼 → 南院…）。
- 每场景：自动缓慢旋转 + 播放讲解，讲完停留 3 秒切下一处。
- 支持暂停、跳过、退出。

### 4.4 移动端

- 单指拖动、双指缩放；
- 陀螺仪需用户点击授权（iOS 需 HTTPS 或 localhost）；
- 底部场景条改成可滑动的大按钮，避免误触；
- 全屏用 CSS 铺满（iOS 不支持全屏 API）。

```js
window.TOUR = {
  title: '铭贤学堂旧址 · 自由游览',
  start: 'gate',
  order: ['gate','waijia','president','chongsheng','inner','shiban','side','guanshang',
          'south-main','alumni','south-fork','tongzhan','south-block','yunbo','intl','loop1','party'],
  scenes: [
    {
      id: 'gate',
      name: '铭贤学校旧址外门',
      pano: 'assets/panoramas/2184.webp',
      panoMobile: 'assets/panoramas-mobile/2184.webp',
      preview: 'assets/previews/2184.jpg',
      initialYaw: 0,
      initialPitch: 0,
      audio: 'assets/audio/chongshenglou.mp3',   // 待确认对应关系
      captions: [],                              // 文稿到位后填 [{t: 0, text: '…'}]
      hotspots: [                                // 二阶段补 yaw/pitch
        { yaw: 1.2, pitch: 0.05, target: 'waijia', label: '去往外院' }
      ],
      pois: [
        { yaw: -0.6, pitch: 0.1, title: '旧址外门', text: '……', ref: '校史馆' }
      ]
    }
  ]
}
```

- 数据内嵌成 JS，**避免 `file://` 下 `fetch` 被浏览器拦截**，保证双击即开。
- 每个场景 `pano` 按设备选择：宽屏用 4096，窄屏用 2048。

## 6. 素材处理规范

| 项目 | 规范 |
| --- | --- |
| 全景尺寸 | 桌面 4096×2048，移动 2048×1024（原图 4480×2240 只做母版留存，不进页面） |
| 格式 | WebP 质量 82；Safari 老版本回退 JPEG（可选） |
| 单张体积 | 4096 档约 1.2–2.5 MB；2048 档约 0.35–0.8 MB |
| 首屏预算 | 首场景 ≤ 2 MB，其余按需加载 |
| 缩略图 | 512×256 JPEG（约 40 KB），场景条用 |
| 占位图 | 64×32 模糊图内联 base64，先显示再替换 |
| 音频 | MP3 128 kbps 单声道（体积小、兼容好），统一到 -16 LUFS |
| 命名 | 用场景 ID（`2184.webp`），中文名放数据里，避免 URL 编码问题 |

处理脚本用 Node（sharp）或 Python（Pillow）一次性跑完，产物放 `assets/`，原图不进页面目录。

## 7. 性能与兼容性

| 项 | 策略 |
| --- | --- |
| 内存 | 场景切换时销毁旧纹理（`viewer.destroy()` 或 setPanorama 替换），手机上最多保留 2 张 |
| 加载 | 先显示占位图 → 加载全景 → 淡入；相邻场景空闲预加载 |
| DPR | 限制 `devicePixelRatio ≤ 2`，避免高分屏爆显存 |
| 弱网 | 显示进度条；加载失败给「重试」按钮 |
| iOS | 全屏用 CSS；陀螺仪需点击授权；`playsinline` 播放音频 |
| 微信内置浏览器 | 不保证全屏和陀螺仪，页面可正常浏览；建议用系统浏览器打开 |
| 本地双击 | 数据内嵌 + 相对路径，`file://` 也能跑（音频/WebGL 正常）；若浏览器限制，则用启动脚本起本地服务 |
| 离线 | 纯静态无外部请求（库、字体、图片全部本地），断网可用 |

### 14.2 与方案的差异

| 方案 | 实际 | 原因 |
| --- | --- | --- |
| 数据内嵌保证 `file://` 可跑 | 改为**必须走本地服务** | ES Module + importmap 在 `file://` 下被浏览器拦截，无法绕过；已用启动脚本兜底 |
| 手势/陀螺仪插件 | 未启用陀螺仪 | 桌面展示为主，避免额外插件体积；后续需要可加 |
| 全部 8 段音频绑定 | 绑定 4 段，其余进讲解库 | 4 段名称在现有 17 个场景中无同名对应，需确认归属 |
| 双分辨率按设备自动选 | 已实现（≤900px 用 2048 档） | 一致 |

### 14.3 验证证据

headless Edge 157 自动化验证：

- 场景条 17 项、讲解库 4 项、首屏背景加载正常
- 点击进入 → 「铭贤学校旧址外门」，`1 / 17`，canvas 创建成功

已知验证限制：headless（swiftshader）截图偏暗、`canvas.toDataURL` 读不到像素，
属无头渲染与 `preserveDrawingBuffer:false` 的固有表现，非页面缺陷。

### 14.4 关于「与原平台保持一致」的实测结论

2026-11-18 用 view-source 逐房间读取原 5itui 后台编辑页的服务端渲染源码，
提取 `window.song` 与 `yaw_pitch`：

| 检查项 | 结果 |
| --- | --- |
| 17 个房间的 `window.song` | **全部为空** |
| 17 个房间的 `yaw_pitch`（初始视角） | **全部 `0,0`** |

原始数据：`mingxian-tour/tools/room-songs.csv`。

**含义**：原平台从未把 8 段 MP3 绑定到任何房间，它们只是上传在素材库里；
也不存在房间级初始视角设置。所以没有可照搬的映射。

**当前处理**：

1. 按名称相同绑定 4 段（校长院／崇圣楼／石板院／观赏楼）——唯一有据可循的对应；
2. 另 4 段（尚德堂、南院别墅、南院4号楼、南院3号楼）无同名场景，留在讲解库可指派；
3. 初始视角与平台一致，均为全景正中；
4. 若要严格还原"平台无绑定"状态，在讲解库里把它们逐条设为「不绑定」即可。

### 14.5 仍需你确认

1. **那 4 段配音是否要挂到某个场景**（听过后在讲解库里下拉选择即可）；
   若确认原平台本就没绑，也可以全部留空。
2. 讲解文稿 → 决定是否加字幕。
3. 落款与素材说明文案（当前刻意留空）。
4. 是否需要场景间方向性热点（画面箭头）。

### 15.2 首次构建失败：Kotlin stdlib 重复类

```
Duplicate class kotlin.collections.jdk8.CollectionsJDK8Kt
  in kotlin-stdlib-1.8.22.jar and kotlin-stdlib-jdk8-1.6.21.jar
```

原因：`androidx.webkit:webkit:1.14.0` 传递依赖 `kotlin-stdlib-jdk8:1.6.21`，
而 `androidx.appcompat:1.7.1` 带 `kotlin-stdlib:1.8.22`，两个版本都提供同名类。

处理：加 `kotlin-bom:1.9.24` 统一版本，并排除 webkit 的 `kotlin-stdlib-jdk7/jdk8`。

### 15.3 壳工程设计

刻意**不用 Capacitor**，写一个极简 WebView 壳（`android-app/`）：

| 关键点 | 做法 | 原因 |
| --- | --- | --- |
| 本地资源 | `WebViewAssetLoader` 映射 `assets/www/` → `https://appassets.androidplatform.net/assets/www/` | `file://` 下 ES Module 会被 CORS 拦，页面直接白屏 |
| importmap 兼容 | 打包时把 `psv.module.js` 里 13 处 `from "three"` 改写成 `from "./three.min.js"` | 老 WebView 不支持 importmap |
| 存储 | `setDomStorageEnabled(true)` | 讲解库绑定要存 localStorage |
| 音频 | `setMediaPlaybackRequiresUserGesture(false)` | 切场景后能自动播配音 |
| 权限 | **零权限**（不申请网络/存储/相机/定位） | 完全离线 |
