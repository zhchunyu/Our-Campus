# OurCampus · 沿途：整套应用预览

2026-11-15。基于主分支 `45c52f7`，采用用户明确选定的第二套“沿途”视觉。版本仍为 1.20 / versionCode 21；本次交付网页与源码预览，不更新 Android 安装包和自动更新元数据。

## 这次改变

四个主入口改为“今天、校园、社区、我的”。白底、深蓝正文、青绿操作色与黄色选中状态贯穿已有页面和弹层；减少重复卡框，保留任务需要的输入与分组。底部导航使用图标、文字和短下划线，清除旧绿色图标底块。

- 今天以真实校园地图、下一次已排课程和常用地点为主。课表未导入、未校准、没有后续安排与时间冲突分别显示，不用示例课程填充。地点历史按账号保存，“最近查看”不冒充实际到访。
- 校园把找地点、吃饭、附近、办事、活动与报修放在一个可检索的入口。餐厅直接进入窗口、实拍菜单、评价与照片。没有真实评价时不补虚构分数，其他餐厅不再套用谷园窗口。
- 去这里先确认出发地点；不会把预设校门当成设备当前位置。新鲜且精度合适的定位可以建议附近校园起点，仍需选择。校园估算与腾讯外部导航的定位计算有明确说明。
- 餐厅与课程打开地点、规划路线、取消或结束后恢复来源。地图上打开餐厅窗口也恢复到同一窗口。
- 社区优先真实内容；空列表不补假动态。地区聊天发送目标跟随阅读地区；阅读“全部”时需明确选择。保留草稿、阅读位置、加载旧消息的位置和原消息定位。
- 顶部消息和社区使用同一聊天页。从提醒、上报记录进入聊天，返回保留原分类及详情；被覆盖的“我的发布”页也正确恢复。上报完成可以打开对应记录。
- 我的采用蓝晒植物默认封面，用户已有自选封面继续保留。头像昵称与私人工具明确分区；本机效果预览与真实访客预览分开。
- 收藏与常用路线按账号保存在本机；退出显示独立的设备记录，旧记录不会自动归给新账号，存储失败显示提示。
- 轻量按压、页面/弹层过渡、照片查看、可选封面动态和返回手势延续同一节奏；减少动态设置继续有效。

## 全应用覆盖

| 页面组 | 本轮结果 |
| --- | --- |
| 今天、课程 | 重排首页；连接课程与建筑；保留导入、校准、日周视图、冲突与账号边界 |
| 搜索、地图、地点、路线、附近 | 共用地点 ID 和来源；增加起点确认；真实腾讯地图及原有回退保留 |
| 餐厅/窗口、评价 | 统一列表、详情、菜单、评价、照片选择/查看；连接去这里；照片接口保持兼容 |
| 办事、报修、活动 | 统一内页；保留官方入口；区分本机模拟与云端上报；修正日期交集 |
| 社区、动态、失物、聊天、游戏 | 统一外围样式和入口；移除混入真实流的示例；保留队友画板、玩家和互动逻辑 |
| 消息、发布、我的发布 | 统一分类、表单和状态；原消息与具体上报记录可以定位 |
| 收藏/路线、个人/访客、账户 | 统一工具与编辑层；账号隔离；公开资料与本机装扮分区；保留登录、验证、找回 |
| 设置/更新、管理、通用弹层 | 共用样式与焦点规则；沿用管理权限、更新签名规则和既有业务表单 |

这是对原有 26 组页面的系统改造，不代表为每个权限和业务状态都做了真实账号端到端验收。管理操作和云端真实提交的限制见下方。

## 明确边界

真实账号登录、手机相册/相机上传、两账号查看私有照片、通知投递及管理员审核没有在本轮云端实操；不能将本地拦截测试视为服务器验收。餐厅照片继续沿用此前已批准的私有照片迁移及兼容接口，本轮没有数据库改动。

封面、签名和标签仍仅保存在本机；真实访客页展示已实际公开的头像、昵称和发言，不显示课表、收藏、路线或本机装扮。公开封面/签名同步需要后续服务端能力，当前界面明确说明保存范围。

正式 Android 覆盖升级仍缺少原发布签名配置。本次不生成替代签名的安装包，不改旧 APK 下载地址。网页包需通过静态 HTTP 服务打开，源码包不含本机环境配置、依赖和签名文件。
