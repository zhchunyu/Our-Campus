# 学生画布细节修订 · 2026-11-13

本轮基于 main `d0eb611`，保留队友新增的你画我猜、玩家互动及电脑预览。应用仍为 1.20 / versionCode 21，仅修改五份界面样式。

## 可见变化

- 统一页面底色、正文、辅助文字与操作色，清理各内页独立使用的绿灰色；评分、提醒、错误保留各自语义色。
- 去掉首页、个人快捷入口、服务、动态、餐厅及内页列表反复出现的横线和竖线，使用间距、字号与对齐表达分组。
- 常用工具改为无边框两列入口；修正图标被旧定位挤到右侧的问题。
- 封面、图片、表单和弹层统一圆角层次；输入焦点只保留一圈清晰轮廓。
- 移动端横向分类保留滑动，去掉突兀的原生滚动条；导航选中状态改为小圆点。
- 路线关闭按钮移到顶部，窄屏无需滚动到底；聊天发送区继续保持可见。

个人封面自定义与已有短过渡继续保留，减少动态效果设置继续有效。游戏仅调整外围控件配色，没有改变绘图画布或调色盘颜色。
