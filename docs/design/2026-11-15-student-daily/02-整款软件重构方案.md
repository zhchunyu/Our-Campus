# OurCampus：整款软件重构方案

2026-11-15 · 设计阶段范围原稿。用户已选定“沿途”，实际实施与验证结果见 [整套应用预览](../../releases/2026-11-15-along-system-preview.md)。下文描述目标，不将未接通的公开封面等能力视为已上线。

## 产品目标

学生不必理解“服务、地点、动态、地图”各自属于哪个模块，也能连贯完成上课、吃饭、办事与交流。设计表达有年轻人的个性，但常用操作直接、状态可信，自己的数据与公开内容边界清楚。

保留现有校园地点、课表导入、餐厅窗口与照片、地区聊天、失物、活动、游戏、发布、消息、账户及管理员能力。整套改造同时包括信息架构、数据连接、返回行为、视觉和动态，不以 CSS 覆盖代替产品改造。

## 四个稳定入口

| 一级入口 | 主任务与内容 | 不应挤进来的内容 |
| --- | --- | --- |
| 今天 | 下一节、当天安排、相关提醒、可自选的常用动作；确认当天没有已排课程时显示下一次已排课程 | 固定艺术封面、永远占位的空课表、大段示例活动 |
| 校园 | 搜地点、餐厅、设施与办事；按找楼/吃饭/办事切换；列表与地图共用选择状态 | 未定位就给出的精确距离、假实时人流、虚构预约/点餐功能 |
| 社区 | 真实动态、活动、失物和同学内容；地区聊天与游戏有稳定入口；提醒和聊天入口始终可达 | 只有功能图标的中转菜单、把公开地区大厅冒充私聊 |
| 我的 | 公开名片、真实访客预览；独立标注的本机效果预览；课表管理、收藏、路线、发布记录；账户和设置 | 把本机装扮说成公开同步、把课表和私人路线暴露给访客 |

消息在各主页面顶部保持同一入口，进入后分“提醒、校园聊天、我的上报”；保存地区与阅读位置。社区保留一级入口，不能为消息重组而删除学生公开交流场景。

顶部消息和社区必须进入同一个地区聊天页面，共用地区、消息锚点、阅读位置和草稿状态；入口只记录不同来源，不能形成两套聊天壳。返回作者页后回到原聊天位置；退出聊天时，来自提醒的回原提醒，来自社区的回原社区位置，不固定跳回首页。

## 五条必须接通的任务

1. **上课**：首页下一节 → 课程详情 → 教室/建筑确认 → 选择起点 → 路线 → 返回原课程。下一节只依据已导入、已校准且在有效学期内的已排课程；未校准、学期过期、未排时间和课程冲突分别说明，不能把缺少安排解释为“无课”，也不推断临时调课。保留教室号，不能可靠匹配时让用户选建筑；不承诺室内导航。
2. **吃饭**：校园/吃饭 → 餐厅 → 窗口与菜单 → 评价与照片 → 写评价或去这里。全流程共用餐厅/窗口 ID，返回保留筛选。看菜单不强制登录，发表时登录并保留草稿。
3. **办事**：按事项搜索 → 资料/材料/官方入口/地点 → 联系或导航。报修从地点和问题进入，上传照片 → 确认提交范围 → 回到该条记录；本机草稿与应用云端提交分别标注。
4. **交流**：消息提醒 → 原地区/原消息定位 → 查看上下文或作者 → 返回原阅读位置 → 返回来源提醒或社区。来源栈须跨作者页、图片预览和地图跳转保留；发送地区默认跟随当前阅读地区，“全部”时明确选择。地区聊天与临时游戏房间的数据寿命分开。
5. **个人展示**：我的 → 编辑头像/封面/签名 → 核对保存范围与结果 → 真实访客预览或本机效果预览。真实访客预览只读取已保存且实际公开的字段，不能混入本机私有内容或未保存草稿；未接通公开能力的封面、签名只能标为“本机效果预览，他人不可见”。私人工具在访客页不存在；公开封面、签名与分享需另做服务端字段、存储和权限，未接通前不假装发布成功。

标为“我的”的课表、收藏、路线和本机发布历史必须按账号隔离，退出或切换账号后不沿用上一账号的私人记录。本机保存不等于云端同步；旧设备共用记录需明确归属或保留设备级标识，不能静默归入新登录账号。

## 全页面覆盖矩阵

| 页面组 | 重做范围 | 关键状态与承接 |
| --- | --- | --- |
| 今天首页 | 课程、相关提醒、常用动作、内容排序 | 已/未导入、未校准、学期过期、已排课程为空、跨天、登录前后、过期提醒 |
| 课程 | 日/周课表、导入、预览、校准、课程详情 | 解析错误、重复导入、未排时间、课程冲突、账号隔离、建筑未匹配 |
| 校园搜索 | 地点/餐厅/设施/服务聚合结果 | 搜索范围明确，无结果、历史与清除；不声称可搜全部聊天 |
| 地图 | 地图/列表切换、地点标记、搜索结果 | 当前选择与来源保留；Key/网络/配额失败可回退 |
| 地点详情 | 地址/用途/关联事项/收藏/导航 | 来源、未知开放时间、相关活动/反馈 |
| 路线 | 起点确认、模式、下一步、完整路线 | GPS/手选/演示区别；不可用、同起终点、到达 |
| 附近设施 | 分类、定位、设施详情、补充 | 定位前仍可查；距离是直线估算，精度如实显示 |
| 餐厅/窗口 | 吃饭入口、餐厅列表、窗口列表、详情、菜单 | 真实图片优先；缺图、缺价格、加载失败 |
| 评价 | 筛选、排序、作者、评价详情、写评价 | 1–3 张图、压缩/上传进度、失败保留、移除/撤回 |
| 办事目录 | 事项搜索、资料、联系方式、官方外链 | 缺时间/电话不编造；外部办理与应用内提交区分 |
| 报修 | 地点、分类、描述、照片、确认、记录详情 | 本机/云端范围；提交中、防重复、错误重试 |
| 活动 | 日期/时间意图、列表、详情、收藏、地点 | 今天/未来/已结束、跨午夜、来源；不发明报名系统 |
| 社区首页 | 阅读内容优先、分类、发布、聊天/游戏入口 | 示例与真实流分开；空态不补假热度 |
| 校园动态 | 列表、地区/类型、详情、发布 | 首页和社区进入同一详情，不做两套信息壳 |
| 失物招领 | 分类、搜索、发布、照片、详情、完成/撤回 | 丢失/捡到区分、联系范围、表单草稿 |
| 地区聊天 | 历史、输入、图片、地区、撤回、转动态 | 多入口共用页面与状态；翻页、原消息定位、来源栈、离线、键盘、小屏 |
| 你画我猜 | 选地区/房间、玩家、画板、猜词、互动 | 保留画笔颜色与玩法；临时计分不称长期排行榜 |
| 消息 | 提醒列表、详情、聊天入口、上报进度 | 未读、加载失败、原文已撤回、返回位置 |
| 发布 | 选发布类型、关联地点、照片、预览、提交结果 | 业务表单分流，先确定餐厅/窗口再评价 |
| 我的发布 | 分类记录、状态、具体详情、返回 | 直接定位该条记录，不能只打开另一张列表 |
| 收藏/路线 | 保存内容、空态、删除、继续任务 | 账号隔离、设备记录归属、退出/切换账号；不承诺云端同步 |
| 个人/访客页 | 自设封面、头像、签名、内容、真实访客预览、本机效果预览 | 真实访客页只展示实际公开字段；本机预览明确他人不可见，私人工具不进入公开内容区 |
| 账户 | 登录、注册、验证、找回、头像昵称 | 登录后回原任务，草稿保留，退出说明 |
| 设置/更新 | 通知订阅、地图/路线偏好、减少动态、版本 | 权限拒绝、更新失败、安装来源与签名 |
| 管理区域 | 审核、窗口维护、地点与反馈管理 | 普通用户不见管理动作，服务端权限不变 |
| 通用弹层 | 标题、关闭、底部动作、图片查看、确认 | 返回栈、安全区、键盘、焦点、手势可取消 |

## 视觉规则

- 产品主要字号 14–16px，标题用于定位任务，不用超大口号占首屏；不写“这里可以做什么”“开启校园新体验”。
- 不把每件事塞进有边框的卡片；只有有独立状态的课程/行程可用一个明显的承载面。列表以对齐、间距和内容本身区分。
- 丰富颜色有用途：行动色一套，课程/内容类别一套，错误和状态单独定义；拒绝逐项随机粉彩、全页灰绿和极端荧光。
- 学生的个性来自自己设置的封面、照片、签名与真实内容；不强制校园插画，也不将一幅默认静物当产品主视觉。
- 图标使用统一库与字重，常用入口配短文字；不设计难认的抽象符号替代实际任务名。
- 登录前后、空内容、加载、失败与长文本都与常规页面一起设计。

## 动态规则

| 动作 | 动态表达 | 限制 |
| --- | --- | --- |
| 课程打开地点 | 课程中的地点信息连续进入详情 | 保留原始课程，180–240ms，不抢焦点 |
| 列表切地图 | 同一选中地点保持身份、地图展示对应区域 | 不重新跳回校园中心，不伪造定位 |
| 打开照片 | 从点击照片扩展到完整图，关闭回原位置 | 可用按钮关闭，不只依赖手势 |
| 切日/筛选 | 日期选择和内容短距离移动 | 可点击替代滑动，读取时保持稳定 |
| 个人封面 | 用户选择静止/轻微移动 | 只在个人展示场景，后台停止，减少动态时关闭 |
| 上传/提交 | 明确进度与完成反馈 | 不用虚假动画代替真实结果；失败保留输入 |

## 验收方式

以完整任务而非单页截图验收：已导入课表能到建筑；未知教室能手选；未定位不冒认当前位置；从餐厅能直达窗口评价；登录后回原草稿；消息能回原文；提交后能找到对应记录；访客看不到私人工具。各链路都覆盖返回、大字体、320px、键盘、无网、减少动态与权限拒绝。

视觉稿的隐私边界单独验收：课表、收藏、路线绝不能排在公开内容下，只能出现在明确的本人私人工具区域，真实访客页不得出现。生成的方向图如果误排，一律记录为缺陷并要求修正，不作为后续实现依据。

同时核对未校准、学期过期、未排时间与课程冲突的文案；分别验证真实访客预览和本机效果预览，并测试退出、换账号后没有上一账号私人记录。聊天须从顶部消息和社区各走一遍，经过作者、图片或地图后仍能回到原消息、阅读位置和入口来源。

本轮先完成整套流程与视觉方向的可审阅稿；未选定视觉前不再次覆盖生产界面或发布新安装包。

## 参考与迁移判断

- [NUS uNivUS 官方教程](https://about-univus.nus.edu.sg/univus-tips/)：高频组件可置顶、部分查询访客可用、课程接上课地点。借鉴任务优先级，不照搬它的公交实时数据。
- [Citymapper GO](https://citymapper.com/news/597/go-your-personal-trip-assistant)：行程中突出当前相关的一步。借鉴分阶段操作，不把路线控制台全铺首屏。
- [DICE 活动指南](https://dicefm.zendesk.com/hc/en-gb/articles/22365220986897-How-to-find-events-you-ll-love-on-DICE)：时间意图、附近与内容探索。借鉴活动组织，不发明本项目尚无的购票或报名能力。
- [Are.na 内容集合](https://help.are.na/docs/getting-started/channels)：私人/公开边界与内容组织。借鉴个人表达与权限分离，不复制其品牌样式。
