## 2. 现状与资源盘点

### 2.1 平台情况（5itui）

- 5itui 是面向房产/空间展示的 VR 全景在线制作平台，能力包括：全景图片上传、场景（房间）管理、跳转标记、兴趣点标签、作品发布与嵌入代码。
- 平台条款明确：**用户上传/创作的作品（全景图片、视频、音频、文字、交互设置）知识产权归用户所有**（《用户服务协议》第 3.1 条），平台仅在提供服务所必需范围内存储与展示（3.2 条）。因此把自己制作的作品迁移到自建应用，权利上没有障碍。
- 但同一条款 **4.3(2) 禁止使用爬虫、脚本批量采集平台数据**。因此不要写脚本抓取平台资源，应走「官方导出 / 客服协助 / 使用自己留存的原始文件」三条正路。
- 平台体量很小（第三方统计月访问约 300 次），**存在改版或停服风险**，不建议把最终展示长期押在在线嵌入上。
- 站点响应头未发现 `X-Frame-Options`/CSP 限制，技术上 iframe 嵌入大概率可行，但需用真实作品链接验证。

### 2.4 铭贤学堂旧址的史实底座

- 山西铭贤学校旧址位于太谷区杨家庄村西、山西农业大学校内，2013 年列为**第七批全国重点文物保护单位**；时代为清至民国，由崇圣楼东/中/西院、曲尺形水榭院、杭氏楼、韩氏楼、田氏楼、亭兰图书馆、嘉桂科学楼及别墅群等 40 栋建筑构成（[山西省文物局](https://wwj.shanxi.gov.cn/wwaqzjzrrgs/jzs/tgx/gb_30674/202109/t20210908_1989142.shtml)）。
- 1907 年孔祥熙创办铭贤学堂；1909 年迁入太谷孟家花园（今址）；1951 年由山西省人民政府接管，改为山西农学院；1979 年更名为山西农业大学（[山西农业大学历史沿革](https://www.sxau.edu.cn/xxgk2/lsyg.htm)、[山西省文物局](http://wwj.shanxi.gov.cn/wwzy/wwlb/bkydww/sjzdwwbhdw/dspsb/202109/t20210908_1983113.shtml)）。
- 这些是讲解稿的权威依据；「教会学校」「孔祥熙」「抗战南迁」等表述需按校史馆与思政课口径统一，不能自由发挥。

## 3. 三条实现路线

| 路线 | 做法 | 工期 | 优点 | 主要问题 |
| --- | --- | --- | --- | --- |
| A. 直接嵌入 | iframe / Capacitor WebView 加载 5itui 作品链接 | 0.5–2 天 | 最快，零开发 | 依赖第三方在线服务；广告/水印/UI 不可控；断网即废；小程序 web-view 还需备案域名（5itui 域名无法备案）；平台停服即失效 |
| B. 自建播放器（推荐） | 导出全景图与音频，用 Photo Sphere Viewer / Pannellum 复刻漫游，加入讲解、字幕、知识点、题目、打卡 | 3–6 周 | 完全可控、可离线、可嵌入现有 App、可长期维护、可答辩演示 | 需要原图与音频；需要重新编排内容 |
| C. 视频化降级 | 录屏巡游 + 配音 + 章节字幕，输出 MP4/H5 | 3–7 天 | 最稳、最省事，适合现场答辩与网络差的会场 | 不可自由探索，互动性弱 |

**建议组合**：以 B 为主体（可探索的思政导览），同时产出 C 作为「一键演示版」和断网兜底；A 只用于早期给老师看效果。

## 4. 推荐方案设计

### 4.1 内容结构（思政「一课一品」）

主题建议：**「从孟家花园到山西农大——铭贤旧址里的初心与农脉」**，设置 5–7 个场景节点：

| 节点 | 场景 | 讲解要点 | 思政落点 |
| --- | --- | --- | --- |
| 1 | 校门/旧址入口 | 1907 建校、1909 迁入孟家花园 | 教育救国的起点 |
| 2 | 崇圣楼中院 | 中西合璧的建筑与办学理念 | 文化自信与开放包容 |
| 3 | 亭兰图书馆 | 图书、农科与实业教育 | 知农爱农、躬耕实践 |
| 4 | 曲尺形水榭/孟家花园 | 园林到校园的空间变迁 | 人与自然、校园文脉 |
| 5 | 抗战南迁路线 | 1937 南迁、1940 立案、1951 接办 | 家国情怀与艰苦奋斗 |
| 6 | 今日农大 | 1979 更名、合署改革 | 强农兴农的时代使命 |

每个节点承载：**全景画面 + 配音讲解 + 字幕 + 史料卡片（含出处）+ 1 道随堂小题 + 打卡点**。

### 4.2 功能清单（MVP → 完整）

**MVP（2 周原型）**
- 全景浏览（拖拽/陀螺仪/全屏）
- 场景间跳转（热点）
- 单场景配音播放 + 字幕
- 节点介绍卡片

**完整版（4–6 周）**
- 自动巡游模式（自动转场 + 连续讲解），适合大屏/答辩
- 进度与打卡（本机存储即可，不必上云）
- 随堂题目与得分、结课证书页
- 时间线视图（1907→1951→1979→今）
- 分享卡片/二维码
- 离线包（Service Worker 或 Capacitor 本地资源）
- 无障碍：字幕、倍速、字号

### 4.3 技术选型

| 层 | 方案 | 说明 |
| --- | --- | --- |
| 全景渲染 | [Photo Sphere Viewer 5](https://photo-sphere-viewer.js.org/)（基于 three.js） | 现有工程已依赖 `three@0.186`，可直接复用；支持热点、标记、陀螺仪、VR |
| 备选 | Pannellum | 更轻，功能少一些 |
| 音频/字幕 | HTML5 Audio + 时间轴字幕 | 配音按场景切分，便于跳转 |
| 集成 | 作为 OurCampus 新模块 `/mingxian` | 复用现有 React/Vite/Capacitor、主题、路由与分享 |
| 离线 | Service Worker 缓存 / Capacitor 打包资源 | 每个全景 2–6 MB，8 个场景约 30–50 MB，APK/网页可行；小程序需 CDN |
| 展示 | 自动巡游 + 全屏 + 大屏比例适配 | 答辩/展板场景必备 |

## 6. 合规与审批

| 事项 | 要点 | 责任方 |
| --- | --- | --- |
| 文物影像使用 | 旧址为**全国重点文物保护单位**。教学/公益展示一般可行；出版、商业使用或无人机航拍需另行报批。建议取得学校宣传部/档案馆书面同意 | 学校 |
| 史实审校 | 讲解稿必须经校史馆/档案馆核对，思政表述经马克思主义学院审核 | 内容方 |
| 校名/校徽 | 使用学校名称、标识需授权，避免商业化暗示 | 学校 |
| 配音版权 | 自录配音版权清晰；若用 AI 配音，需按《人工智能生成合成内容标识办法》做标识；背景音乐必须使用可商用授权曲目 | 制作方 |
| 肖像与隐私 | 全景中出现游客/师生面部需模糊处理 | 制作方 |

| 上架形态 | 校内展示用网页/APK 门槛低；若上微信小程序，需教育类目资质、主体认证、ICP 备案与小程序备案 | 学校/学院 |
| 项目验收 | 「一课一品」通常需学院立项、教务处/宣传部评审，建议提前确认验收指标（覆盖人数、课时、成果形式） | 学院 |

## 7. 风险与应对

| 风险 | 等级 | 应对 |
| --- | --- | --- |
| 平台无法导出原图/音频 | 低（已解除） | 2026-11-18 实测：17 张原图与 8 段配音已公开可下载并取回本地；后续只需注意平台若清理旧文件 |
| 5itui 停服或改版 | 中 | 不把最终展示押在在线嵌入；自建资源本地化 |
| 史实/表述被审回 | 中 | 提前把讲解稿送审，按校史馆口径改写；准备 2 版文案 |
| 现场网络差 | 高 | 离线包 + 视频备份 + 本地缓存；答辩前彩排 |
| 全景图过大导致加载慢 | 中 | 多分辨率切片（PSV 支持 equirectangular tiles）或压缩到 4096×2048 |
| 内容工作量被低估 | 中 | 把讲解稿写作单独排期，指定内容负责人 |
| 授权链不清 | 中 | 立项时一次性拿到学校、档案馆、文物部门的书面口径 |
